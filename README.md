# Elison Inc. — Main Organization Website

The flagship website for Elison Inc., showcasing the ecosystem of four interconnected platforms serving creators, businesses, and artists.

## What's Inside

- **OneTime Studios** — Premium studio marketplace for booking and discovery
- **DevHouse AI** — Enterprise automation systems  
- **SplitSheet** — Legal infrastructure for music splits & agreements
- **ELISON** — Creative flagship (artist brand)

## Tech Stack

- **HTML/CSS/Tailwind CSS** — Modern utility-first styling
- **GSAP + ScrollTrigger** — Smooth scroll animations
- **Accessibility** — WCAG compliant, keyboard navigation, reduced-motion support
- **Responsive** — Mobile-first design

## Getting Started

### Local Development

1. Open `index.html` in your browser directly:
   ```bash
   open index.html
   ```

2. For better development experience, use a local HTTP server:
   ```bash
   python3 -m http.server 8000
   # Then visit http://localhost:8000
   ```

### Deployment

#### GitHub Pages
This site is optimized for GitHub Pages deployment:

1. Enable GitHub Pages in repository settings
2. Select `main` branch as source
3. Site will be live at `https://ElisonInc.github.io/website`

#### Vercel
Can also be deployed to Vercel for higher performance:

1. Connect GitHub repo to Vercel
2. Deploy (no build step required for static HTML)
3. Custom domain: `elison.inc`
